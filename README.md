# Evelyn Nguyen — finance portfolio

Static bilingual portfolio for https://evelyn-pg-nguyen.github.io/.

English pages live at the repository root; their French equivalents are in `fr/`.
The EN / FR controls link to the same page in the other language. Navigation keeps
the current language. All pages share `assets/style.css`.

The five pages are Home, Dashboards, Modeling, AI Automation, and Degrees & Certificates.
The Modeling page intentionally says that projects are coming soon.
Power BI and YouTube load when a visitor opens the corresponding project.
The embedded report and video retain their original language.

Publish with GitHub Pages from the `main` branch, root directory. No build tools or
paid hosting are required. Update both language versions when editing content.
